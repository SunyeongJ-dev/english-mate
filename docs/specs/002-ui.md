# 002: UI

## Goal

The whole page looks finished and is easy to use on phone and desktop: the app shell, the input screen, the loading and error states, and the result card.

## Design

The look is calm and minimal: white and neutral greys, one blue accent, and colour for the level. The tables below are the source for colours and type, and the In scope list is the source for everything else. The input, loading, and error screens use the same colours and type.
| Token | Value | Used for |
| --- | --- | --- |
| Accent | `#2563EB` (Tailwind `blue-600`) | Primary buttons (send, `New sentence`), the selected language button, the logo mark, focus rings, and the textarea's focus border |
| Accent text | `#1D4ED8` (`blue-700`) | The `Formal` and `Casual` labels |
| Accent tint | `#EFF6FF` (`blue-50`), border `#DBEAFE` (`blue-100`) | The sidebar background on desktop, the header background on mobile |
| Text | `#171717` (`neutral-900`) | Body text |
| Muted text | `#525252` (`neutral-600`) | `Your sentence`, `Note`, `No chats yet`, unselected language buttons |
| Subtle text | `#737373` (`neutral-500`) | The footer, the textarea placeholder, the input hint |
| Surface | `#F5F5F5` (`neutral-100`) | The input box |
| Lines | `#E5E5E5` (`neutral-200`), `#D4D4D4` (`neutral-300`) | Dividers in the result card; borders of the input box and the language switcher |
| Error | `#DC2626` (`red-600`) | Error messages, the counter over 1000 characters |
| Font | Geist | Everything |

| Level | Badge (white text on) | Card tint | Card border | Icon |
| --- | --- | --- | --- | --- |
| `natural` | `#15803D` (`green-700`) | `#F0FDF4` (`green-50`) | `#BBF7D0` (`green-200`) | Check |
| `slightly_awkward` | `#B45309` (`amber-700`) | `#FFFBEB` (`amber-50`) | `#FDE68A` (`amber-200`) | Exclamation |
| `awkward` | `#B91C1C` (`red-700`) | `#FEF2F2` (`red-50`) | `#FECACA` (`red-200`) | Cross |

Every value is from Tailwind's palette, so the code uses the class names above instead of hex values. White (`#FFFFFF`) is the page background and the colour of text on the accent and on badges.

## In scope

### App shell

- [ ] The browser tab title is `English Mate`, and the page description says what the app does.
- [ ] The page uses the Geist font everywhere.
- [ ] The page uses a light theme only. It looks the same when the OS is in dark mode. `app/globals.css` has no dark-mode styles.
- [ ] Primary buttons, the selected language button, and focus rings use the accent. No element uses black as an accent.
- [ ] `English Mate` has a logo mark next to it: a blue rounded square with a white `E`. It is a placeholder until there is a real logo.
- [ ] On desktop (`md` and wider), the sidebar shows on the left with the accent tint, and the main area is on the right.
- [ ] On mobile (narrower than `md`), the sidebar is hidden. The header has the accent tint and shows the logo mark and `English Mate` on the left and the language switcher on the right.
- [ ] The sidebar shows the logo mark, `English Mate`, and `No chats yet`. The history list is spec 003.
- [ ] The sidebar has no Settings button, no `Guest` label, and no button that does nothing.
- [ ] The footer shows `© <year> English Mate`.

### Input screen

- [ ] The heading is a warm, casual greeting: `What do you want to say today?`
- [ ] The text under the heading is `Write one English sentence to see how natural it sounds.`
- [ ] The textarea placeholder is `Type your sentence here...`.
- [ ] The textarea has focus when the page loads.
- [ ] Enter submits. Shift+Enter adds a new line. Enter while an IME is composing does not submit.
- [ ] Under the input, a hint says `Press Enter to check. Shift+Enter for a new line.` It is hidden on mobile.
- [ ] Once the text is longer than 900 characters, a counter shows `<count> / 1000` at the bottom of the input box. It counts characters after trimming spaces at the start and end, the same text the page sends to the route.
- [ ] Over 1000 characters, the counter turns red. The send button works, and submitting shows the route's `Input is too long.` message.

### Loading state

- [ ] While the request runs, the textarea and send button are disabled and the button shows a spinner.
- [ ] `Checking your sentence...` shows under the input while loading, and screen readers announce it (`aria-live="polite"`).
- [ ] The spinner does not spin when the user prefers reduced motion.

### Error state

- [ ] The error message shows under the input in the error colour, with `role="alert"`.
- [ ] The user's text stays in the textarea after an error, so they can fix it.
- [ ] The error message goes away as soon as the user edits the text.
- [ ] Error text comes only from the constants in `app/lib/types.ts` or the route. There are no error messages other than the ones in spec 001.

### Result card

- [ ] The card shows the user's sentence at the top, under the label `Your sentence`.
- [ ] The card shows the level as a solid badge with white text, holding the level's icon and the fixed sentence from `LEVEL_LABELS`. The colours and icons are in the level table in "Design". The level is never shown by colour alone.
- [ ] The card's background and border take the level's tint and border colour from the same table.
- [ ] The card shows three sections with visible labels on a white panel inside the card: `Formal`, `Casual`, and `Note`, in that order. `Formal` and `Casual` use the accent text colour, and `Note` uses the muted text colour.
- [ ] The labels and values use `<dl>`, `<dt>`, and `<dd>`: one `<dt>` and one `<dd>` per section.
- [ ] `Formal` and `Casual` each have a copy button at the right of their row.
  - It is an icon button with `aria-label` `Copy formal sentence` or `Copy casual sentence`, and a touch target of at least 44px.
  - Clicking it copies that sentence with `navigator.clipboard.writeText`. The icon changes to a check and `Copied` shows next to it for 2 seconds. Screen readers announce `Copied`.
  - If copying fails, `Couldn't copy` shows for 2 seconds instead.
  - `Note` has no copy button.
- [ ] The labels `Your sentence`, `Formal`, `Casual`, `Note`, `Copied`, and `Couldn't copy` are in English. Translating them is spec 004.
- [ ] Long text wraps inside the card. Nothing scrolls sideways.
- [ ] When the result appears, focus moves to the card's heading, so screen reader users hear the result.
- [ ] Changing the language while a result is showing does not change that result. It keeps the language it was checked in.
- [ ] The `New sentence` button goes back to the input screen, with an empty textarea that has focus.

### Accessibility and layout

- [ ] The page works at 320px wide without horizontal scrolling.
- [ ] Every button, the textarea, and the language switcher show a visible focus ring in the accent colour.
- [ ] Text and badge colours meet WCAG AA contrast (4.5:1 for normal text).
- [ ] Everything can be done with the keyboard only.

### Code

- [ ] Icons are inline SVG. The app uses no icon or UI component library.
- [ ] `app/api/chat/route.ts`, `app/lib/prompt.ts`, and the response shape behave as spec 001 says.
- [ ] `app/page.tsx` and the components call Claude only through `fetch("/api/chat")`.

## Out of scope

- Showing and saving history in the sidebar, and a mobile menu for it (spec 003)
- Translating the UI labels and error messages (spec 004)
- Dark mode (spec 005)
- A copy button for `Note`
- Accounts and settings
- Animations other than the loading spinner

## Done when

- The browser tab says `English Mate`.
- On a 1280px-wide window, the sidebar shows on the left. On a 375px-wide window, it is hidden, the header shows `English Mate` and the language switcher, and nothing scrolls sideways. The same is true at 320px.
- On load, the heading says `What do you want to say today?`, and typing goes straight into the textarea without clicking it.
- The sidebar has no Settings button and no `Guest` label.
- Typing 900 characters shows no counter. Typing 901 shows `901 / 1000`. Typing 1001 shows a red `1001 / 1000`, and submitting shows `Input is too long.`
- On a result, clicking the copy button next to `Formal` puts Claude's formal sentence on the clipboard and shows `Copied` for 2 seconds. The same works for `Casual`.
- With the OS in dark mode, the page looks the same as in light mode.
- Submitting `I am agree with you` shows `Checking your sentence...` while loading, then a card with `Your sentence`, an amber or red level badge with an icon, a card tint that matches the badge, and the labels `Formal`, `Casual`, and `Note`.
- Every colour class in `app/page.tsx`, `app/layout.tsx`, and `app/components/` is one of the Tailwind classes in the two tables in "Design", or white. No class uses `black`.
- Submitting `Thanks!` shows a card with a level badge.
- Submitting `이것은 테스트입니다` shows `Please enter one English sentence.`, keeps the text in the textarea, and the message goes away after typing one character.
- Clicking `New sentence` shows the input screen with an empty, focused textarea.
- With a result showing, switching from `EN` to `KO` does not change the card.
- The whole flow (type, submit, read the result, `New sentence`) works with the keyboard only.
- `pnpm run lint` and `pnpm run build` pass.
