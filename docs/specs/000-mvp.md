# 000: MVP

## Goal

The user can enter an English sentence into the input, and get Claude's feedback.

## In scope

- [x] The user enters one English sentence.
- [x] The app shows an error message when the input is empty or is not an English sentence.
- [x] The result shows the naturalness level as a fixed sentence.
- [x] For valid input, Claude returns the level as a value only (`natural`, `slightly_awkward`, or `awkward`). The app maps each value to a fixed display sentence; Claude never generates it.
- [x] The result shows two alternative sentences, one formal and one casual.
- [x] The result shows a brief (no more than 5 sentences) explanation of why Claude thinks it is or is not natural.

## Out of scope

- Handling multi-sentence input (spec 001)
- Exact JSON shape and rules for invalid input (spec 001)
- Polished UI design, including the result card (spec 002)
- Saving results in `localStorage` (spec 003)
- Choosing Claude's response language (spec 004)

## Done when

- Entering `I am agree with you` shows a level, two alternatives, and an explanation.
- Entering an empty input shows an error message that says `Please enter your sentence.`
- Entering `이것은 테스트입니다` shows an error message that says `Please enter one English sentence.`
